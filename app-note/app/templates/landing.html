Folders & nesting

Organize notes in trees of folders, color-code them, and move notes between folders from a right-click menu or the editor.

  • Per-folder colors
  • Move-to-folder from context menu

Tags that connect

Tag notes to link ideas across folders, then filter by tag to pull related work together no matter where it lives.

  • Create & color tags

Desktop + Web

Your notes, everywhere you are

Pair the web app with the NoteStack desktop client using an API token from Settings. Changes flow both ways and conflicts are handled safely.

1

Pull on startup

The desktop app pulls your latest notes from the server the moment it opens, so you always start from the current state.

2

Push after every save

Edits sync to the web 3 seconds after each save. Press Ctrl+S and the web view updates in step.

3

Resolve conflicts

If a note changes on both sides, a banner appears. Open the side-by-side diff and keep one version or merge them.

🔗 Connect from Settings → generate an API token, then paste it into the desktop app's SYNC section. A sync log is available for troubleshooting.
