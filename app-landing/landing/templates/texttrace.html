Features

Everything stays on your machine

No data leaves your device. No API calls. No accounts. Just fast, private, semantic search.

On-Device Embeddings

Runs a real embedding model locally using your CPU/GPU. No server round-trips, no latency from the cloud.

Zero Data Leakage

Your files are never uploaded, logged, or shared. TexTrace has no network access — by design.

Semantic Understanding

Search by meaning, not just keywords. "meeting about budget cuts" finds the right file even if those exact words aren't in it.

Set & Forget Directories

Point TexTrace at your folders once. It watches for changes and keeps the index updated automatically in the background.

Instant Results

Vectorized search returns results in milliseconds, even across thousands of files. Sub-50ms typical query time.

Global Hotkey

Summon TexTrace from anywhere with ⌘K. Search, hit enter, and you're in the file. Feels like it's built into your OS.

Customizable models

For Power Users

Tune it your way

Don't like the default model? Swap it out. Want to adjust chunk size, overlap, or similarity thresholds? Go ahead. TexTrace gives you full control over the embedding pipeline — no locked-in defaults.

  • Swap embedding models (ONNX, GGUF, custom-trained)
  • Adjust chunk size, overlap, and splitting strategy
  • Configure similarity thresholds and result count
  • Export and import vector indices for backup
  • CLI interface for scripting and automation
textrace.config.toml
# Embedding model configuration
[model]
name = "all-MiniLM-L6-v2"
backend = "onnx"
dimensions = 384
 
[indexing]
chunk_size = 512
chunk_overlap = 64
splitter = "recursive_text"
 
[search]
top_k = 10
similarity_threshold = 0.65
rerank = true
 
[directories]
paths = [
  "~/Documents",
  "~/Projects",
  "~/Notes"
]
watch = true
