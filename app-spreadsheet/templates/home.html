About TinyXL

A focused, cross-platform spreadsheet reader/editor for quickly reviewing and manipulating large sheets — right in your browser.

✨ Key Features

  • Zero-install viewer — Open any browser, no Excel required. Works identically on Linux, Windows, and macOS.
  • Full layout memory — Column widths, row heights, sticky rows, header rows, cell colors, and column types all survive page reloads via SQLite persistence.
  • Linked filter views — Create persistent named filtered views of any sheet. They appear as tabs alongside regular sheets for instant access.
  • 50-level undo/redo — Full-state snapshots for data and layout changes. Never lose your work.
  • Inline editing — Double-click any cell to edit, with multi-line textarea support. Cut, copy, and paste across cells.
  • Smart paste conflict resolution — Three choices when pasting over data: insert rows & columns, move conflicts to a new sheet, or cancel.
  • Header row awareness — Designate header rows that stay pinned during sorting and are excluded from filtering.
  • Smart column type detection — Auto-classifies columns as numeric or text; manually override with a single click.
  • Cell color customization — Pick text and background colors for individual cells or selections. Custom swatches saved in your browser.
  • Bulk row height adjustment — Algorithm computes optimal heights based on wrapped text content across the entire sheet.
  • Auto-save — Debounced persistence to SQLite at 400ms. Close the page without worry.

📁 Supported Formats

.xlsx .xlsm .xls .xlsb .csv .txl

The .txl format packages all sheets, layout state, and linked filters into a single portable file for sharing.

🔧 Technical Stack

  • Backend: Python Flask + pandas + openpyxl
  • Database: SQLite for layout persistence, file registry, and recent files
  • Frontend: Vanilla JavaScript with full undo/redo, clipboard integration, and context menus
  • Dependencies: Only 5 Python packages — runs comfortably on low-resource machines

📦 Export & Share

Export any workbook as a .txl file — a single JSON package containing all sheet data, layout preferences, and linked filter views. Share it with colleagues or archive it for later. Import restores the full workspace exactly as you left it.

Built with Flask, pandas, and vanilla JavaScript.
