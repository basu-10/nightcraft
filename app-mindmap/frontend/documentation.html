01 — Content

Card Types

Three distinct card types let you capture research data in the format that fits best — rich text, images, or structured tables.

Text 📝

Rich Text Cards

Full rich text editing with bold, italic, underline, inline highlights, hyperlinks, and bullet lists. Powered by Lexical editor.

  • Bold Ctrl+B
  • Italic Ctrl+I
  • Underline Ctrl+U
  • Inline highlights & links
Image 🖼️

Image Cards

Embed images from URLs, local uploads, clipboard paste, or drag-and-drop. Auto-resizes for preview.

  • URL input or file upload
  • Clipboard paste support
  • Drag & drop files
  • Built-in image editor
Table 📊

Table Cards

Mini-spreadsheet right on the canvas. Add/remove rows and columns, edit cells with rich text, import from Excel/CSV.

  • Dynamic rows & columns
  • Rich text in cells
  • Excel/CSV import
  • XLSX export
02 — Relationships

Connectors & Edges

Link cards together with labeled arrows to build a web of relationships — showing how ideas, sources, and data connect.

Source Article
A card containing the original research paper summary.
derives from
Analysis Note
Interpretation and findings derived from the source.
01
Drag-to-connect — Click a port on any card edge and drag to another card to create a connection.
02
Labeled edges — Each connector can have a label indicating the relationship type (e.g. "supports", "contradicts", "derived from").
03
Smart routing — Cubic Bezier curves with arrowheads stay attached when you move connected cards.
03 — Organization

Tags & Hierarchy

Tags provide the semantic layer of your board. Organize them in parent-child trees and use them to filter, color-code, and classify cards.

source › interview › transcript
methodology › quantitative
confidence › high
01
Hierarchical nesting — Drag a tag onto another to create a parent-child relationship. Breadcrumb paths display automatically.
02
Semantic coloring — A card's first tag determines its accent color — affecting the header border, selection glow, and badge.
03
Tag properties — Tags can define property schemas (e.g. confidence: low/medium/high) for structured metadata on cards.
04 — Workspace

Canvas & Navigation

An infinite canvas with smooth pan & zoom, multiple canvases per book, and a powerful search & filter system.

Pan & Zoom

  • Scroll to zoom in/out
  • Middle-click drag to pan
  • Ctrl+0 to reset zoom
  • Fit to Screen button in Edit menu

Multi-Select

  • Ctrl+click to toggle cards in/out of selection
  • Shift+click for range selection
  • Drag header of any selected card to move all
  • Batch delete from context menu

Search & Filter

  • Real-time search by title, content, tags
  • Filter by card type (Text / Image / Table)
  • Filter by tag or tag hierarchy
  • Quick view presets (e.g. High Confidence)

View & Edit

  • Double-click card body to edit
  • Pencil icon toggles edit/view mode
  • Esc saves and exits edit mode
  • Maximize button for focused editing
